# ❄️ HVAC Master Mobile

A mobile-friendly HVAC training and troubleshooting game designed for students, apprentices, and service technicians.

Players diagnose equipment faults, complete repairs, earn certifications, level up their technician skills, and master residential HVAC systems through realistic service scenarios and interactive mini-games.

---

## 🎮 Features

### Career Mode
- Realistic HVAC service calls
- Customer complaints and diagnostics
- Earn XP and money
- Level progression system
- Technician achievements and badges

### Diagnostic Training
Learn how to identify:

- Refrigerant leaks
- Dirty filters
- Failed capacitors
- Electrical faults
- Airflow issues
- Heat pump problems

### Interactive Mini-Games

#### 🔋 Capacitor Replacement
Perform safe lockout procedures and replace failed capacitors in the correct order.

#### ❄️ Refrigerant Charging
Adjust system charge to achieve target superheat and subcooling values.

#### 🔍 Leak Detection
Use a virtual leak detector to locate refrigerant leaks before time runs out.

#### ⚡ Electrical Troubleshooting
Use HVAC diagnostic logic to find failed components with minimal testing.

## 🚀 Getting Started

### Run Locally

1. Download or clone the repository

```bash
git clone https://github.com/YOURUSERNAME/hvac-master-mobile.git
```

2. Open:

```text
index.html
```

in any modern web browser.

No installation required.

---

## 🌐 Deploy on GitHub Pages

1. Push the project to GitHub
2. Open Repository Settings
3. Navigate to:

```text
Settings → Pages
```

4. Select:

```text
Branch: main
Folder: /root
```

5. Save

Your game will be available at:

```text
https://YOURUSERNAME.github.io/hvac-master-mobile/
```
